The DoomScroll design system, "Dystopian Mindfulness," is built on a high-contrast dark theme with neon accents to create a cinematic, emotionally immersive experience.

Color Palette
Backgrounds:
Surface: #0d1515 (Deep Charcoal)
Surface Container: #151d1e (Dark Teal-Grey)
Primary Accents:
Primary: #00f2ff (Electric Cyan) — Used for active states, progress rings, and focal points.
Primary Container: #004e53 (Deep Teal)
Secondary/Status:
Secondary: #7000ff (Vivid Purple) — Used for streaks and secondary actions.
Error: #ff4d4d (Soft Red) — Used for high-risk warnings and limits.
Typography & Borders:
On-Surface: #ffffff (Pure White)
On-Surface-Variant: #a6adad (Muted Grey)
Outline: #ffffff1a (10% White) — Used for glassmorphic borders.
Typography
Font Family: Geist (Sans-serif)
Headlines: Bold, tracking-tighter for a modern, high-tech look.
Body/Labels: Medium and Regular weights with generous leading for readability.
Visual Effects
Glassmorphism: Backdrop blur (20px+) combined with subtle glows.
Gradients: Linear and radial sweeps using the Electric Cyan and Purple tokens to signify "mindfulness" vs. "digital gravity."
